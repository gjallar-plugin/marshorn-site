The Platform

Security evaluation that behaves like a lab, not a demo.

Most agentic security benchmarks rely on transcripts and self-reported outcomes. Gjallar instead runs full episodes inside isolated virtual environments with independently observable state, so a claimed compromise, detection, or containment can be verified against the environment itself.

Dual-agent episodes

An attacker agent and a defender agent act independently inside the same environment. Neither sees the other's reasoning — only what its own sensors and sight channels expose, mirroring real red-team / blue-team separation.

Ground-truth oracles

Success is measured by independent, environment-level checks — a domain object modified, a service ticket issued, a file read — never by asking a model whether it thinks it succeeded.

Replayable fixtures

Every scenario is versioned and hashed. The same fixture digest reproduces the same topology and starting state, enabling apples- to-apples comparisons across models, prompts, and defenses.

Technology

Built on real virtualization, not simulated transcripts.

Isolated QEMU labs

Multi-VM topologies run under QEMU with no public network egress. The shipped path is a Linux enterprise-slice fixture; the active build path is a three-node Windows AD lab (domain controller, member server, workstation) driven by a WinRM control plane.

Chain-of-node objectives

Attacker goals are modeled as ordered technique chains — for example domain authentication → resource access → service ticket acquisition → remote session → object control — so partial progress and technique-specific failure are both observable.

Frozen baselines

Once a scenario is validated across repeated runs, its baseline is frozen and versioned. New attacker or defender strategies are regression-tested against that frozen baseline before any claim of improvement is accepted.

Human-gated policy synthesis

Findings from the attack loop can draft defensive policy candidates, but nothing is auto-enabled. Every candidate goes through an explicit, human-approved promotion gate before it can affect a live governance surface — the same discipline as the Gjallar Plugin action boundary.

Differentiation

A different layer from autonomous pentesting.

Established autonomous pentesting products optimize for finding and validating vulnerabilities. Public benchmarks optimize for comparing model capability. Gjallar asks a narrower governance question: do agent controls still hold under reproducible adversarial pressure?

Autonomous pentesting

Find exploitable paths

Broad discovery and operational validation are the product. Gjallar does not claim broader coverage than established platforms in this category.

Capability benchmarks

Compare model performance

Standardized tasks produce useful rankings, often as public goods. They do not necessarily connect failures to an operational policy surface.

Gjallar

Test and improve governance

Fixture-versioned episodes expose policy gaps; independent oracles verify them; human-approved candidates can return to the governance boundary.

Defensibility thesis: the moat is not a fixture file alone. It is the accumulated mapping between replayable environments, verified failure modes, policy candidates, and customer-specific governance integration. This thesis still requires external validation.
