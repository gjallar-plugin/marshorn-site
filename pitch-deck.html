02 · Problem

Agent security is almost impossible to verify.

Self-report

The model says it succeeded. That is not evidence. Tool-using agents can claim a compromise the host never shows.

One-off tests

A demo or pentest cannot be rerun when the model, prompt, or policy changes. No fixture digest, no regression.

Wrong layer

Scanners find bugs. Leaderboards rank models. Neither asks whether your agent controls still hold under pressure.

Organizations are giving agents shells, identity, and APIs.02 / 10

03 · Solution

Gjallar: oracle-verified, replayable adversarial evaluation.

Isolated lab

  • QEMU topologies, no public egress
  • Linux enterprise-slice
  • Three-node Windows AD

Independent oracle

  • Ticket, share, directory object
  • Checked out-of-band
  • Never trust attacker stdout

Replay

  • Frozen, hashed baselines
  • Same digest, same start
  • Comparable multi-model runs

Evaluate in the lab → draft policy candidates → human-gated governance.03 / 10

04 · How it works

Two questions, two observers.

Oracle

Did the goal happen? Identity chain, files, tickets—measured on the host or DC.

Defender

Would a defender notice? Audit/EDR next. A single event is not proof of malice.

Identity-chain control plane today: lab WinRM into the foothold VM. Not a Beacon.04 / 10

06 · Differentiation

A different job from pentest and benchmarks.

Autonomous pentesting

Find exploitable paths. Operational discovery is the product. Gjallar does not claim broader coverage.

Capability benchmarks

Rank models on standardized tasks. Failures rarely return to an operational control surface.

Gjallar

Same frozen lab. Oracle-verified outcome. Improve the governance boundary under repeatable pressure.

Moat thesis: mapping replayable failures to human-gated policy—not a fixture file alone.06 / 10

07 · Market

Who buys a verifiable agent-security lab.

Security product teams

Regression-test detection or agent controls before a release. Same fixture after a model or rule change.

AI platform / governance

Widen tool access only after the same lab still holds. Human-gated promotion, not auto-enable.

Research labs

Compare models on oracle-confirmed chains, with repeats—not a single lucky run.

Offer today: scoped research pilots. Not a public SaaS.07 / 10

10 · NVIDIA / GPU

GPUs for repeatable agent evaluation—not training a foundation model.

What we will run

Batch LLM attacker/defender episodes on frozen fixtures. Parallel inference, not pretraining. Compare models on the same AD and Linux baselines.

What we need

Cloud GPU (e.g. L4/A10) and API inference credits so multi-model replay is not gated by one workstation. Local NVIDIA GPU only after utilization justifies it. AD guests stay CPU/virtualization-bound.
